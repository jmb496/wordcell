# WordCell Serif card-letter font

## Description

Adds scripts/build-font.py, commits the Fraunces-instance subset src/ui/assets/wordcell-serif.woff2 and OFL.txt, records source URLs and SHA-256s in data/README.md, wires @font-face (font-display: block) in src/ui/app.css and the index.html preload, applies the face to the placeholder card letters, and extends entry 3's pwa precache spec to the font.

## Acceptance Criteria

Verify: uv run scripts/build-font.py reproduces the committed woff2 byte-for-byte, the woff2 covers A–Z and u only, OFL.txt is committed, data/README.md records the source URLs and SHA-256s, the built CSS declares the family WordCell Serif (quote style free) with font-display: block, the build holds the font once with the preload href equal to the @font-face URL, the placeholder cards render in the face, and the pwa precache check finds the font with revision null.

**Build precondition:** clean tree on `epic-1-scaffold`.

**Delta checks (delta-checks.md rows for CAP 4):**

- `index.html` font preload (CAP 4 part): the preload `href` in the built `index.html` equals the hashed font URL in the CSS.
- Font subset (SPEC CAP-4 success): `uv run scripts/build-font.py` reproduces the committed `src/ui/assets/wordcell-serif.woff2` byte-for-byte from the checksum-pinned source; the woff2 covers A–Z and `u` only (cmap shown in the plan); `OFL.txt` is committed; the build holds the font once; the `pwa` precache check also finds the font with `revision: null`.

**Font declaration and provenance (build-notes CAP-4, AD-18 Font):**

- `@font-face` `"WordCell Serif"`, `font-display: block`, in `src/ui/app.css` (build-notes CAP-4); source URLs and SHA-256s in `data/README.md` (AD-18 Font).

**Script contract (build-notes CAP-4, AD-18 Font, SPEC fail-fast; AGENTS.md rule 6):**

- uv inline-script header: `requires-python = ">=3.12"`; `fonttools` and `brotli` pinned with `==`; `[tool.uv] exclude-newer` set to the pin date. Reproducibility is claimed for the recorded Python and uv versions.
- Paths resolve from the repo root (`Path(__file__).resolve().parent.parent`), so the script works from any cwd.
- Source: `google/fonts` `ofl/fraunces/Fraunces[SOFT,WONK,opsz,wght].ttf` (the upright variable TTF, not the Italic) at a pinned commit (raw URL containing the commit hash, with `[`, `]` and `,` percent-encoded), downloaded to `generated/font/` (git-ignored) as `generated/font/Fraunces[SOFT,WONK,opsz,wght].ttf` and `generated/font/OFL.txt`.
- Module-level constants in the script: `TTF_URL`, `TTF_SHA256`, `OFL_URL`, `OFL_SHA256`, each a single line `NAME = "<value>"` (each SHA constant matched exactly once by `^NAME = "([0-9a-f]{64})"$`, each URL constant exactly once, multiline, by `^NAME = "(https://raw\.githubusercontent\.com/[^"\s]+)"$`), each SHA equal to its `data/README.md` line, written in ticket 1.2's format under a `## Font sources` heading appended after the existing `enable1.txt` bullet: one bullet per source file, starting ``- `Fraunces[SOFT,WONK,opsz,wght].ttf` `` and ``- `OFL.txt` `` (unencoded names; the URLs stay percent-encoded), each prefix found exactly once, giving licence (SIL OFL 1.1), download date and raw URL, then an indented `SHA-256: <hex>` line as the bullet's last line (the shape of the `enable1.txt` bullet). In each font bullet the raw URL sits alone on its own indented line with no trailing punctuation, matched exactly once in the bullet span by `/^[ \t]+(https:\/\/raw\.githubusercontent\.com\/\S+)$/`. A bullet span ends at the next `^- ` or `^#` line.
- build-notes' "checked against data/README.md" is met by the in-script constants plus the `AD-18` hash parity test (ticket 1.2 precedent); the script does not parse the README at runtime.
- Bootstrap: before the first run, the builder downloads both files from the pinned raw URLs, computes their SHA-256 with `sha256sum`, records them in the script and `data/README.md`, and shows that output in the plan.
- A cached `generated/font/` file (TTF or `OFL.txt`; the rule covers both) whose SHA-256 mismatches → exit non-zero naming the file and telling the user to delete it; no output written. The script first verifies every existing cached file (failing on any mismatch), then downloads the missing ones in TTF → `OFL.txt` order. The script creates `generated/font/` and `src/ui/assets/` with `mkdir(parents=True, exist_ok=True)`. Download only when no cached file exists: to a temp file `generated/font/<name>.part` opened with truncating write (`wb`, replacing any stale one; same filesystem, atomic rename), renamed to the cache path only when its hash matches, otherwise deleted, exit non-zero, no output written; a `.part` file is deleted on any failure and ignored by the cache-exists check. Download timeout: the `urlopen(..., timeout=60)` socket timeout. Any download error (non-200, timeout, no network) exits non-zero before either output (`wordcell-serif.woff2`, `OFL.txt`) is written; a verified file already renamed into the cache may stay. The script prints "cache hit" or "downloaded" per file.
- Instance wght 600, opsz 48, SOFT 0, WONK 0; subset; woff2. The `TTFont` is opened with `recalcTimestamp=False`, and the instanced/subset font object gets `font.flavor = "woff2"` and `font.recalcTimestamp = False` before `font.save(path)`, so `head` timestamps stay fixed. All other instancer and subsetter options stay at the pinned fontTools defaults (`instantiateVariableFont` with the axis dict only; subsetter `Options()` except `name_IDs`).
- "A–Z and `u` only" means the union of code points across every Unicode cmap subtable (`isUnicode()`) of the output equals exactly U+0041–U+005A plus U+0075 (27 code points); unmapped glyphs such as `.notdef` are allowed. The script asserts this on the in-memory subset before saving, exits non-zero otherwise, and prints that sorted union (the cmap evidence) and the woff2 byte size (DESIGN.md "well under 20 KB"). The plan reports the size and flags ≥ 20,000 bytes (KB = 1,000 bytes per A-A4) as a deviation (no script failure; DESIGN.md states an expectation, not a limit). "Covers A–Z and `u` only" is verified by plan evidence (script assertion, printed cmap, byte-for-byte `git diff`), not by an automated test.
- The subset keeps the subsetter's default name IDs plus 13 and 14 (licence records; ID 0, the copyright, stays). `src/ui/assets/OFL.txt` is downloaded from `ofl/fraunces/OFL.txt` at the same pinned commit (raw URL), checked against its SHA-256 constant and written on every run as the verified downloaded bytes (binary write, no newline translation). The builder confirms in the plan that the pinned `OFL.txt` declares no Reserved Font Name; if it does, stop and report.
- `wordcell-serif.woff2` and `OFL.txt` are written only after both hashes and the cmap assertion pass: both output `.part` files (siblings) are written first, then both `os.replace` into place; any output `.part` is deleted on failure; no `.part` remains in `src/ui/assets/` after any run.

**Wiring:**

- `@font-face` in `src/ui/app.css`: `font-family: "WordCell Serif"`, `src: url("./assets/wordcell-serif.woff2") format("woff2")`, `font-weight: 600`, `font-style: normal`, `font-display: block` (DESIGN.md card-letter; AD-15's `document.fonts.load('600 1em "WordCell Serif"', 'W')`). `app.css` must pass `biome check` (Biome does not check Svelte `<style>` blocks); double quotes in `App.svelte` CSS are a style note.
- The AD-15/AD-16 boot font check (`document.fonts.load`, fatal surface) is out of scope (epic 3, SPEC Non-goals); DESIGN.md's "a failed font load is surfaced … not hidden" is deferred there; it is cited only so the descriptors match that later query; `src/main.ts` does not change.
- `index.html` preload: `<link rel="preload" as="font" type="font/woff2" crossorigin href="/src/ui/assets/wordcell-serif.woff2">`, so Vite rewrites it to the same hashed file as the CSS (build-notes CAP-4; without `crossorigin` the font downloads twice). Only the preload `<link>` is added; title, `viewport-fit` and `theme-color` are the PWA packaging ticket's (delta-checks row, CAP 5).
- `vite.config.ts` (root config file): read Scaffold deltas but change only `build.assetsInlineLimit` here; the other `vite.config.ts` deltas are the PWA packaging ticket's. Set `build.assetsInlineLimit: (file) => (file.endsWith('.woff2') ? false : undefined)` so a `.woff2` is never inlined as a `data:` URL and other assets keep Vite's default. Why: a 27-glyph subset can fall under Vite's 4096-byte default and would be inlined as `data:`. This is an addition beyond Scaffold deltas, justified by SPEC CAP-4 "font once"; it neither contradicts nor removes any Scaffold delta. It is a technical default under the owner's standing delegation for technical choices (rule 7); record it for the spine Scaffold-deltas update. The plan lists it under deviations and as a spine Scaffold-deltas addition for the epic retrospective / spine update (not the D8 AGENTS.md audit).
- `.gitattributes`: add `src/ui/assets/OFL.txt -text` and `src/ui/assets/*.woff2 binary` (ticket 1.2's `data/enable1.txt -text` precedent).
- Use of the face: the placeholder `.card` letters in `src/ui/App.svelte` use `font-family: "WordCell Serif", serif; font-weight: 600` (the `.card` rule's weight changes from 700 to 600); no other text in the placeholder uses it (the tray word line adopts it with its epic, per DESIGN.md). The placeholder renders the engine letter `QU` as is; the `Qu` treatment (DESIGN.md) belongs to the board epic; the printed cmap is the evidence for `u`. Card sizes and the real board layout stay with the board epic. `dist-smoke` still passes.
